Syllabus Mapping: Theoretical Foundations of the Adaptive System

1. Theoretical Computer Science (TCS - 24CSPCC501C):

  • Finite Automata (Module I): The 4-step diagnostic wizard runs on a formal sequential DFA: Q = {S_VEHICLE_PROFILE, S_SYMPTOMS_QUESTIONNAIRE, S_DIAGNOSTIC_CHECKS, S_FINAL_DECISION}, ensuring progressive state transitions with clean backward navigation.
  • Context-Sensitive Grammar (Module III): Restricts input symptom alphabets based on the vehicle domain $V \in \{ ext{CAR}, ext{TWO\_WHEELER}, ext{EV}, ext{COMMERCIAL\_TRUCK}\}$. Impossible states (e.g. asking an EV owner about engine oil or exhaust smoke) are eliminated through formal state constraints.

2. Soft Computing (SC - 24CSPCC502C):

  • Mamdani Fuzzy Inference System (Module 2): Powers the 🟢 DIY vs 🟡 Inspection vs 🔴 Mechanic decision boundary. Fuzzifies Mechanical Risk ($R$), Repair Complexity ($C$), and Check Severity ($S$) into linguistic sets and calculates the crisp classification threshold using Centroid Defuzzification (Center of Gravity / COG).

3. Artificial Intelligence & Machine Learning (AIML):

  • Contextual Symptom Classifier: Expert decision tree evaluating user symptoms (chain slack, battery voltage, brake wear, charging fault) conditioned on vehicle architecture.
  • Adaptive Diagnostic Question Engine: Automatically tailors targeted physical check questions according to the identified subsystem.
